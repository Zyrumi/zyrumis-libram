# 1.2.0

Libram now stays out of sight on characters that aren't paladins: no minimap button, addon menu entry or settings pages.

Class quests: click a chain to put a map pin on the next quest giver. Rewards show as real item icons with tooltips.

Forever's Camp Benefits now count as the blessing they can't stack with (Fish Bowl = Kings, Mana Well = Wisdom, Lodestone = Might), so you aren't nagged to cast over them.

Fixed the class quest window sometimes opening empty, and class detection failing when opened during combat.
